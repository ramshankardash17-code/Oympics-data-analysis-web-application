# 🏅 Olympics Data Analysis Web App

## 📌 Project Overview

The **Olympics Data Analysis Web App** is an interactive web application developed using **Python and Streamlit**.

The application analyzes historical Olympic Games data and provides insights through tables, statistics, and visualizations.

Users can explore overall Olympic trends, analyze medal tallies, compare countries, and study athlete-level performance.

---

## 🎯 Objectives

- Analyze historical Olympic Games data.
- Explore medal-winning performances of different countries.
- Understand participation and performance trends over the years.
- Analyze country-wise and athlete-wise Olympic performance.
- Present the analysis through an interactive web application.

---

## 🚀 Features

### 🏆 Medal Tally

Users can select a particular year and country to view the medal tally.

The application displays:

- Gold medals
- Silver medals
- Bronze medals
- Total medals

### 📊 Overall Analysis

Provides an overall analysis of the Olympic Games, including:

- Number of editions
- Number of cities
- Number of sports
- Number of events
- Number of athletes
- Participating nations
- Trends over the years

### 🌍 Country-wise Analysis

Allows users to select a country and analyze:

- Medal performance over the years
- Sports in which the country performed
- Athletes representing the country
- Medal-winning trends

### 🏃 Athlete-wise Analysis

Provides analysis of individual athletes, including:

- Athlete participation
- Age distribution
- Height and weight
- Sports participation
- Medal performance
